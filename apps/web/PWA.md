# 生成一个链接，让手机「添加到主屏幕」变成桌面 App（PWA）

不需要 Mac，不需要苹果开发者账号。

## 1. 生成文件

```bash
pnpm --filter @cgo/web build:artifact
```

得到 `apps/web/dist-pwa/` 文件夹（index.html、manifest、sw.js、icons/）。

## 2. 放到一个 https 网址上（任选其一）

PWA 必须通过 **https** 网址打开（本地双击文件不行）。

- **最快（约 2 分钟）：Netlify Drop**
  打开 https://app.netlify.com/drop ，注册一个免费账号（不注册的话网站只保留很短时间），把 `dist-pwa` 文件夹整个拖进去，
  马上得到一个 `https://xxx.netlify.app` 链接。可以在站点设置里改成好记的名字。
  在中国大陆访问可能偏慢或不稳定，先用家里的网络试一下。
- **国内访问更稳：** 腾讯云 / 阿里云的静态网站托管。用自己的域名需要先做 ICP 备案。
- **已经有自己的服务器或网站：** 把 `dist-pwa` 里的文件上传到任意目录即可（全部是相对路径）。

## 3. 在手机上装到桌面

**iPhone**：用 **Safari** 打开链接（微信里打开的话，点右上角 ··· 选「在 Safari 中打开」）
→ 点底部的「分享」按钮 → 「**添加到主屏幕**」→ 添加。

**安卓**：用 Chrome 或手机自带浏览器打开 → 菜单 → 「**添加到主屏幕**」/「安装应用」。

桌面上会出现 AI Dad 图标，点开全屏运行，第一次打开后断网也能用。

## 4. 更新

重新执行第 1 步，把新的 `dist-pwa` 再拖一次（Netlify 里点 Deploys → 拖到上传区）。
手机上的 App 下次联网打开时自动更新。
